# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-09-19

### Added

- GitHub Action for automatic README translation through DeepL, OpenAI, or Ollama.
- Markdown protection for code, links, URLs, HTML, images, and comments.
- Glossary support, dry-run mode, generated commits, tests, and release workflow.
